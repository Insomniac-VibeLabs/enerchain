# Mint-path schematic

Edition: doc-0.6. File: [mint-path.svg](mint-path.svg).

The drawing is the hardware-only issuance path. Generation feeder, supply tap before the shunt, shunt and divider into a fixed-function metrology core, CF pulse into a secure element that signs ML-DSA-44, tamper mesh to zeroize, slept radio to the ledger. No host processor. The budget is the meter burden in [meter-burden.md](../meter-burden.md).
